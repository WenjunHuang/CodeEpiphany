### Code Epiphany 🌟

**A feature-rich plugin designed to streamline coding challenges in JetBrains IDEs.**

🚀 **Code Epiphany** integrates popular competitive programming platforms like LeetCode, HackerRank, and TopCoder into
your IntelliJ IDE. Solve, debug, and optimize coding challenges seamlessly without ever leaving your favorite
development environment.

#### Key Features:

- 🌐 **Platform Integration**: Access problems from LeetCode, HackerRank, and TopCoder directly within JetBrains IDEs.
- ⚡ **One-Click Submission**: Submit your solutions and get instant feedback without switching to a browser.
- 🛠️ **Real-Time Code Testing**: Run and debug your code locally with JetBrain's powerful tools.
- 📊 **Progress Tracker**: Monitor your performance, track solved problems, and identify growth areas.
- 🔄 **Multi-Platform and Multi-Language Support**: Work on problems from multiple platforms (e.g., LeetCode, HackerRank,
  TopCoder) and in multiple programming languages—all within a single project. No need to open multiple IDEs or create
  separate projects, making it perfect for algorithm enthusiasts and learners.
- ✍️ **Multiple Solutions per Problem**: Support writing multiple solutions for the same problem. You can code, test,
  and
  document explanations for each solution, enabling thorough exploration of different approaches.

---

### 🛠️ Installation

1. Open IntelliJ and navigate to **Plugins > Marketplace**.
2. Search for **Code Epiphany** and click **Install**.
3. Restart IntelliJ to activate the plugin.
