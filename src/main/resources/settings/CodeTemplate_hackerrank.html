List of Predefined Variables of HackerRank
${beginRegion}   Single-line comment marking the submission region's start.
${endRegion}   Single-line comment marking the submission region's end.
${challenge.id}   The unique identifier for the challenge.
${challenge.name}   The name of the challenge, e.g., "Birthday Cake Candles".
${challenge.slug}   The URL-friendly identifier for the challenge, e.g., "birthday-cake-candles".
${challenge.description}   A brief description of the challenge.
${challenge.contest}   A contest of the challenge.Such as 'main','project euler'
${challenge.header}   The header section of the challenge code, typically containing include or import statements.
${challenge.template}   The template section of the challenge code, usually defining the algorithm function blueprint.
${challenge.tail}   The footer section of the challenge code, often containing the program's entry point and input parser.
${challenge.code}   The full challenge code, combining header, template, and footer.
${challenge.testCases}   Test Cases
$!velocity.camelCaseName(str)   Converts a string to CamelCase, where the first letter is capitalized.
$!velocity.smallCamelCaseName(str)   Converts a string to camelCase, where the first letter is lowercase.
$!velocity.snakeCaseName(str)   Converts a string to snake_case format.
$!velocity.dateTime()   Returns the current date and time formatted as 'yyyy-MM-dd HH:mm:ss'.
