List of Predefined Variables for AtCoder
${beginRegion}   Single-line comment marking the submission region's start.
${endRegion}   Single-line comment marking the submission region's end.
${challenge.id}   A unique identifier for the challenge.
${challenge.problemIndex}   A unique identifier for the challenge in its contest, e.g. A,B,C...
${challenge.contestId}   A unique identifier for the contest.
${challenge.contestTitle}   Title of the contest.
${challenge.codeDojo}   The platform identifier, e.g., "atcoder".
${challenge.name}   The name of the challenge, e.g., "Birthday Cake Candles".
${challenge.title}   The title of the challenge, e.g., "Birthday Cake Candles".
${challenge.language}   The programming language for the code, e.g., Java, C++, Rust.
${challenge.languageVersion}   The version of the programming language used.
$!velocity.camelCaseName(str)   Converts a string to CamelCase, capitalizing the first letter.
$!velocity.smallCamelCaseName(str)   Converts a string to camelCase, with the first letter lowercase.
$!velocity.snakeCaseName(str)   Converts a string to snake_case format.
$!velocity.dateTime()   Returns the current date and time formatted as 'yyyy-MM-dd HH:mm:ss'.
