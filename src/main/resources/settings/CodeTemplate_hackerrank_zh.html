HackerRank 预定义变量列表
${challenge.id}   题目的唯一标识符。
${challenge.name}   题目的名称，例如 "生日蛋糕蜡烛"。
${challenge.slug}   URL 友好的题目标识符，例如 "birthday-cake-candles"。
${challenge.description}   题目的简要描述。
${challenge.contest}   题目所属的比赛，例如 "main" 或 "project euler"。
${challenge.header}   题目代码的头部部分，通常包含 include 或 import 语句。
${challenge.template}   题目代码的模板部分，通常定义算法函数的框架。
${challenge.tail}   题目代码的尾部部分，通常包含程序的入口点和输入解析器。
${challenge.code}   完整的题目代码，包含头部、模板和尾部部分。
$!velocity.camelCaseName(str)   将字符串转换为驼峰式命名，首字母大写。
$!velocity.smallCamelCaseName(str)   将字符串转换为小驼峰式命名，首字母小写。
